# 🤖 ربات تلگرام خدمات

راهنمای کامل برای نصب و اجرای ربات تلگرام شما

## 📋 مراحل نصب

### 1️⃣ نصب Python (اگر نصب نشده باشد)
```bash
# برای Windows
# از سایت python.org دانلود کنید

# برای Mac/Linux
brew install python3
```

### 2️⃣ نصب کتابخانه‌های مورد نیاز
```bash
pip install -r requirements.txt
```

### 3️⃣ دریافت Token از BotFather

1. به تلگرام وارد شوید
2. `@BotFather` را جستجو کنید
3. دستور `/newbot` را بزنید
4. نام و username ربات را انتخاب کنید
5. Token دریافت شده را کپی کنید

### 4️⃣ تنظیم فایل

فایل `telegram_bot.py` را باز کنید و این خط را تغییر دهید:

```python
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"
```

به:

```python
BOT_TOKEN = "توکن خود را اینجا بگذارید"
```

همچنین username کانال خود را مقدار دهید:

```python
CHANNEL_USERNAME = "username_kanaleshan"  # بدون علامت @
```

## ▶️ اجرای ربات

```bash
python telegram_bot.py
```

## 📝 مراحل کار ربات

```
1. کاربر /start را فشار می‌دهد
   ↓
2. ربات شماره تلفن را درخواست می‌کند
   ↓
3. کاربر شماره را اشتراک می‌کند
   ↓
4. منو سه گزینه‌ای ظاهر می‌شود:
   • دریافت دوره رایگان
   • ارتباط با پشتیبانی
   • دوره ها
   ↓
5. بر اساس انتخاب، ربات برای عضویت در کانال دعوت می‌کند
   ↓
6. کاربر دکمه "عضو کانال شدم" را فشار می‌دهد
   ↓
7. ربات اطلاعات مربوط به انتخاب نشان می‌دهد
```

## 🗄️ دیتابیس

اطلاعات کاربران در فایل `users.db` ذخیره می‌شود که شامل:
- شناسه کاربر
- شماره تلفن
- وضعیت عضویت در کانال
- تاریخ پیوستن
- آخرین فعالیت

## ⚙️ سفارشی‌سازی

### تغییر متن‌های ربات

تمام متن‌های پاسخ را می‌توانید در توابع تغییر دهید.

### افزودن دوره‌های جدید

در تابع `course_selection` داده‌های دوره‌های خود را اضافه کنید.

### افزودن ویژگی‌های جدید

می‌توانید handler های جدید اضافه کنید:

```python
application.add_handler(CommandHandler("help", help_command))
```

## 🐛 رفع مشکلات

### ربات جواب نمی‌دهد
- اطمینان حاصل کنید Token درست است
- اینترنت خود را بررسی کنید
- ربات را دوباره شروع کنید

### خطای import
```bash
pip install --upgrade python-telegram-bot
```

### مشکلات دیتابیس
دیتابیس را پاک کنید و دوباره شروع کنید:
```bash
rm users.db
python telegram_bot.py
```
